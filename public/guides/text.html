Complete guide to Text & Code

A practical guide to the 17 Text & Code tools on Utilixo: what each one does, when to use them, and how your data stays on your device.

This guide covers the 17 utilities in the Text & Code category on Utilixo. Each one is a small, focused page that does a single job — Base64 Encode / Decode, Duplicate Line Remover, Hash Generator, HTML Entity Converter — without asking you to sign up or send anything to a server.

Every tool on this site runs locally in your browser. The moment you open a page, the code is already on your device; the numbers or text you type are processed there and are discarded as soon as you close the tab. That makes these pages fast, but it also means they keep working when your connection is slow or unavailable.

What is in this category

  • Base64 Encode / Decode — Encode and decode Base64 with correct UTF-8 handling, so emoji and accents survive the round trip.
  • Duplicate Line Remover — Remove duplicate lines from a list, with options to trim whitespace, ignore blank lines and sort.
  • Hash Generator — Generate MD5, SHA-1, SHA-256 and SHA-512 checksums locally. Nothing is uploaded.
  • HTML Entity Converter — Escape and unescape HTML entities so markup shows up as text instead of rendering.
  • JSON Formatter & Validator — Pretty-print, minify, and validate JSON instantly. Runs entirely in your browser.
  • JSON to TypeScript Converter — Generate TypeScript interfaces from any JSON sample, including nested objects and arrays.
  • JWT Decoder — Decode a JSON Web Token and read its header and payload. Decoding only — the signature is not verified.
  • Markdown to HTML — Convert Markdown to clean HTML with a live preview. Supports headings, lists, code, links and emphasis.
  • Number to Words — Spell out numbers in English words, including decimals and negative values.
  • Regex Tester — Test JavaScript regular expressions against sample text and inspect every match and group.
  • Slug Generator — Turn headlines into clean, URL-safe slugs with optional lowercasing and separator choice.
  • SQL Formatter — Beautify SQL with upper-cased keywords and one clause per line.
  • Text Case Converter — Convert between UPPER, lower, Title Case, camelCase, snake_case, kebab-case and more.
  • Text Diff Checker — Compare two blocks of text line by line and see exactly what was added, removed or kept.
  • URL Encoder / Decoder — Percent-encode and decode URL components. Encode only what needs encoding.
  • Word & Character Counter — Count words, characters, sentences, paragraphs and estimated reading time.
  • XML Formatter — Pretty-print XML markup and check whether it is well-formed.

When these tools help

The Text & Code category has 17 focused tools, including Base64 Encode / Decode, Duplicate Line Remover and Hash Generator. Each page shows its own input fields and one action button; the result appears only after you press it.

Change an input and press the button again: the new result replaces the previous one and replaces it in the same results panel. Where a page has a Copy button, you can take the value straight to your clipboard.

Why everything runs on your device

A Text & Code calculation that sent your inputs to a server would leave a copy somewhere else. Here the JavaScript on each page does the work on your own device, so nothing you type is stored. The formulas and conversion factors live in the page itself, so the same input always gives the same result; where a method has limits such as rounding, regional conventions or financial assumptions, the tool page states them.

Common questions

Do I need to create an account?

No. There is no registration, no email address and no quota. Open any tool and use it as often as you like, free of charge.

Are the results accurate enough for professional work?

The tools use standard formulas and official conversion factors, and each page states which method it applies. They are intended for everyday calculations and quick checks; for regulated financial, medical or legal decisions, always confirm with a qualified professional.

Can I use the output elsewhere?

Yes. Most tools offer a copy button that places the result on your clipboard and confirms with an on-screen message. Generator tools may offer a download instead. Nothing is watermarked or locked.
