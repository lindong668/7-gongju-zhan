À propos de Compresseur d’Images

Réduisez JPEG, PNG et WebP directement dans votre navigateur. Cliquez sur Calculer : le résultat s’affiche dans le panneau de résultats. Tout se passe localement dans votre navigateur, rien n'est envoyé. Seul le résultat actuel s'affiche — sans historique ni comparaison côte à côte.

Compresseur d’Images lit « Choisir une image », « Qualité », « Largeur max (px) » et « Format de sortie » dans le formulaire et écrit la réponse dans le panneau de résultats — '+w+'×'+h+' px · '+icSize(blob.size)+'. Aucun compte, aucun envoi au serveur : le JavaScript de la page travaille sur votre appareil.

Comment utiliser cet outil

  1. Ouvrez Compresseur d’Images depuis la catégorie Générateurs & utilitaires, ou trouvez-le avec la recherche en haut de page.
  2. Remplissez les champs affichés : « Choisir une image », « Qualité », « Largeur max (px) » et « Format de sortie ».
  3. Cliquez sur Calculer. Le nouveau résultat remplace le précédent ; seul le calcul en cours est affiché, jamais deux résultats côte à côte.
  4. Utilisez Copier pour copier le résultat. Un message n’apparaît que si du contenu a réellement été copié.

Exemple concret

À l’ouverture, ces valeurs sont présentes : Largeur max (px) = 1600. Cliquez une fois sur Calculer pour voir la présentation du résultat, remplacez-les par vos données puis cliquez à nouveau : le nouveau résultat remplace l’ancien.

Questions fréquentes

Mes saisies sont-elles envoyées ?

Non. Compresseur d’Images traite « Choisir une image », « Qualité », « Largeur max (px) » et « Format de sortie » avec JavaScript dans le navigateur. Saisies et résultat restent sur votre appareil, Utilixo n’en garde aucune copie.

Puis-je comparer plusieurs résultats ?

Pas côte à côte. Chaque clic sur Calculer recalcule à partir des saisies courantes et écrase le résultat précédent. Notez vous-même les valeurs antérieures.

Y a-t-il une particularité avec Compresseur d’Images ?

'+w+'×'+h+' px · '+icSize(blob.size)+'

Comment récupérer le résultat ?

Après un résultat, cliquez sur Copier. Aucun message de réussite n’apparaît si le résultat est vide.

Faut-il un compte ou payer ?

Non. Compresseur d’Images est gratuit, sans inscription et sans limite. Ouvrez la page et utilisez-le.
