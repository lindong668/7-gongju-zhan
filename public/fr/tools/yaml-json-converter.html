Convertissez YAML en JSON et JSON en YAML. Cliquez sur Convertir : le résultat s’affiche dans le panneau de résultats. Tout se passe localement dans votre navigateur, rien n'est envoyé. Seul le résultat actuel s'affiche — sans historique ni comparaison côte à côte.

Comment utiliser cet outil

  1. Ouvrez Convertisseur YAML ↔ JSON depuis la catégorie Convertisseurs, ou trouvez-le avec la recherche en haut de page.

Questions fréquentes

Mes saisies sont-elles envoyées ?

Non. Convertisseur YAML ↔ JSON traite les saisies avec JavaScript dans le navigateur. Saisies et résultat restent sur votre appareil, Utilixo n’en garde aucune copie.

Puis-je comparer plusieurs résultats ?

Pas côte à côte. Chaque clic sur Convertir recalcule à partir des saisies courantes et écrase le résultat précédent. Notez vous-même les valeurs antérieures.

Y a-t-il une particularité avec Convertisseur YAML ↔ JSON ?

Prend en charge le sous-ensemble courant : mappings, séquences, scalaires, booléens, nombres et null. Les ancres, alias et flux multi-documents ne sont pas gérés.

Comment récupérer le résultat ?

Après un résultat, cliquez sur Copier la sortie. Aucun message de réussite n’apparaît si le résultat est vide.

Faut-il un compte ou payer ?

Non. Convertisseur YAML ↔ JSON est gratuit, sans inscription et sans limite. Ouvrez la page et utilisez-le.
