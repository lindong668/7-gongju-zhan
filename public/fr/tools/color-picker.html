À propos de Sélecteur de Couleur

Choisissez une couleur et lisez HEX, RGB, HSL et contraste. Cliquez sur Exécuter : le résultat s’affiche dans le panneau de résultats. Tout se passe localement dans votre navigateur, rien n'est envoyé. Seul le résultat actuel s'affiche — sans historique ni comparaison côte à côte.

Sélecteur de Couleur lit « Couleur », « Teinte », « Saturation % » et « Luminosité % » dans le formulaire et écrit la réponse dans le panneau de résultats — Le contraste suit la formule WCAG de luminance relative. 4,5:1 est le seuil AA pour le texte courant. Aucun compte, aucun envoi au serveur : le JavaScript de la page travaille sur votre appareil.

Comment utiliser cet outil

  1. Ouvrez Sélecteur de Couleur depuis la catégorie Générateurs & utilitaires, ou trouvez-le avec la recherche en haut de page.
  2. Remplissez les champs affichés : « Couleur », « Teinte », « Saturation % » et « Luminosité % ».
  3. Cliquez sur Exécuter. Le nouveau résultat remplace le précédent ; seul le calcul en cours est affiché, jamais deux résultats côte à côte.
  4. Utilisez Copier HEX pour copier le résultat. Un message n’apparaît que si du contenu a réellement été copié.

Exemple concret

Saisissez vos valeurs dans les champs et cliquez sur Exécuter. Après chaque modification, un nouveau clic recalcule à partir des valeurs courantes et remplace le résultat précédent.

Questions fréquentes

Mes saisies sont-elles envoyées ?

Non. Sélecteur de Couleur traite « Couleur », « Teinte », « Saturation % » et « Luminosité % » avec JavaScript dans le navigateur. Saisies et résultat restent sur votre appareil, Utilixo n’en garde aucune copie.

Puis-je comparer plusieurs résultats ?

Pas côte à côte. Chaque clic sur Exécuter recalcule à partir des saisies courantes et écrase le résultat précédent. Notez vous-même les valeurs antérieures.

Y a-t-il une particularité avec Sélecteur de Couleur ?

Le contraste suit la formule WCAG de luminance relative. 4,5:1 est le seuil AA pour le texte courant.

Comment récupérer le résultat ?

Après un résultat, cliquez sur Copier HEX. Aucun message de réussite n’apparaît si le résultat est vide.

Faut-il un compte ou payer ?

Non. Sélecteur de Couleur est gratuit, sans inscription et sans limite. Ouvrez la page et utilisez-le.
