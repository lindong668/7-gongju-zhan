Testeur de Regex

Testez les expressions régulières JavaScript avec correspondances en direct. Saisissez vos valeurs et cliquez sur le bouton pour voir le résultat.

À propos de Testeur de Regex

Testez les expressions régulières JavaScript avec correspondances en direct. Cliquez sur Tester : le résultat s’affiche dans le panneau de résultats.

Testeur de Regex lit « Motif », « Drapeaux » et « Texte de test » dans le formulaire et écrit la réponse dans le panneau de résultats. Aucun compte, aucun envoi au serveur : le JavaScript de la page travaille sur votre appareil.

Comment utiliser cet outil

  1. Ouvrez Testeur de Regex depuis la catégorie Texte & code, ou trouvez-le avec la recherche en haut de page.
  2. Remplissez les champs affichés : « Motif », « Drapeaux » et « Texte de test ».
  3. Cliquez sur Tester. Le nouveau résultat remplace le précédent ; seul le calcul en cours est affiché, jamais deux résultats côte à côte.
  4. Utilisez Copier pour copier le résultat. Un message n’apparaît que si du contenu a réellement été copié.

Exemple concret

À l’ouverture, ces valeurs sont présentes : Motif = \b[a-z]+@[a-z]+\.[a-z]{2,}\b; Drapeaux = gi. Cliquez une fois sur Tester pour voir la présentation du résultat, remplacez-les par vos données puis cliquez à nouveau : le nouveau résultat remplace l’ancien.

Questions fréquentes

Mes saisies sont-elles envoyées ?

Non. Testeur de Regex traite « Motif », « Drapeaux » et « Texte de test » avec JavaScript dans le navigateur. Saisies et résultat restent sur votre appareil, Utilixo n’en garde aucune copie.

Puis-je comparer plusieurs résultats ?

Pas côte à côte. Chaque clic sur Tester recalcule à partir des saisies courantes et écrase le résultat précédent. Notez vous-même les valeurs antérieures.

Y a-t-il une particularité avec Testeur de Regex ?

Le résultat dépend uniquement des champs affichés (« Motif », « Drapeaux » et « Texte de test ») ; modifiez-en un et cliquez à nouveau sur Tester.

Comment récupérer le résultat ?

Après un résultat, cliquez sur Copier. Aucun message de réussite n’apparaît si le résultat est vide.

Faut-il un compte ou payer ?

Non. Testeur de Regex est gratuit, sans inscription et sans limite. Ouvrez la page et utilisez-le.
