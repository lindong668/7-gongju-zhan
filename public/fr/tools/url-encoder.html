Encodeur / Décodeur d’URL

À propos de Encodeur / Décodeur d’URL

Encodez et décodez les composants d’URL en pourcentage. Cliquez sur Encoder : le résultat s’affiche dans le panneau de résultats. Tout se passe localement dans votre navigateur, rien n'est envoyé. Seul le résultat actuel s'affiche — sans historique ni comparaison côte à côte.

Encodeur / Décodeur d’URL lit “Texte ou URL” dans le formulaire et écrit la réponse dans le panneau de résultats — Encoder l'URL conserve la structure (/, :, &, =). Encoder un composant échappe tout : à utiliser pour une seule valeur de requête. Aucun compte, aucun envoi au serveur : le JavaScript de la page travaille sur votre appareil.

Comment utiliser cet outil

  1. Ouvrez Encodeur / Décodeur d’URL depuis la catégorie Texte & code, ou trouvez-le avec la recherche en haut de page.
  2. Remplissez les champs affichés : “Texte ou URL”.
  3. Cliquez sur Encoder. Le nouveau résultat remplace le précédent ; seul le calcul en cours est affiché, jamais deux résultats côte à côte.
  4. Utilisez Copier pour copier le résultat. Un message n’apparaît que si du contenu a réellement été copié.

Exemple concret

Saisissez vos valeurs dans les champs et cliquez sur Encoder. Après chaque modification, un nouveau clic recalcule à partir des valeurs courantes et remplace le résultat précédent.

Questions fréquentes

Mes saisies sont-elles envoyées ?

Non. Encodeur / Décodeur d’URL traite “Texte ou URL” avec JavaScript dans le navigateur. Saisies et résultat restent sur votre appareil, Utilixo n’en garde aucune copie.

Puis-je comparer plusieurs résultats ?

Pas côte à côte. Chaque clic sur Encoder recalcule à partir des saisies courantes et écrase le résultat précédent. Notez vous-même les valeurs antérieures.

Y a-t-il une particularité avec Encodeur / Décodeur d’URL ?

Encoder l'URL conserve la structure (/, :, &, =). Encoder un composant échappe tout : à utiliser pour une seule valeur de requête.

Comment récupérer le résultat ?

Après un résultat, cliquez sur Copier. Aucun message de réussite n’apparaît si le résultat est vide.

Faut-il un compte ou payer ?

Non. Encodeur / Décodeur d’URL est gratuit, sans inscription et sans limite. Ouvrez la page et utilisez-le.
