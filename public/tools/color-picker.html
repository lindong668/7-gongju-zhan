About Color Picker

Pick any color and read off HEX, RGB, HSL, plus contrast against black and white. Press Run to see the result in the results panel. Everything runs locally in your browser; nothing is uploaded. Only the current result is shown — no history or side-by-side comparison.

Color Picker reads "Color", "Hue", "Saturation %" and "Lightness %" from the form above and writes the answer into the results panel — Contrast uses the WCAG relative luminance formula. 4.5:1 is the AA threshold for normal text. There is no account, no upload and no server round-trip: the JavaScript on this page does the work on your own device.

How to use Color Picker

  1. Open Color Picker from Generators & Utilities, or find it with the search box in the header.
  2. Fill in the fields shown above: "Color", "Hue", "Saturation %" and "Lightness %".
  3. Press Run. The result replaces whatever was shown before; only the current run is displayed, never two results side by side.
  4. Use Copy HEX to put the result on your clipboard. A message appears only when something was actually copied.

A worked example

Enter your own values in the fields above and press Run. Change any input and press again; the result is recalculated from the current inputs and replaces the previous one.

Frequently asked questions

Is what I type uploaded anywhere?

No. Color Picker processes "Color", "Hue", "Saturation %" and "Lightness %" with JavaScript inside your browser. Your inputs and the result stay on your device; Utilixo keeps no copy of them.

Can I keep several results to compare?

No. Each press of Run rebuilds the result from the current inputs and overwrites the previous one. To compare runs, note the earlier result down yourself.

Anything specific to watch with Color Picker?

Contrast uses the WCAG relative luminance formula. 4.5:1 is the AA threshold for normal text.

How do I take the result away?

Press Copy HEX after a result appears. The copy button only reports success when there is content to copy.

Do I need to sign up or pay?

No. Color Picker is free, needs no registration and has no usage limit. Open the page and use it.
