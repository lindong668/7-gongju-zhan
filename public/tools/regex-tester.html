About Regex Tester

Test JavaScript regular expressions against sample text and inspect every match and group. Press Test to see the result in the results panel. Everything runs locally in your browser; nothing is uploaded. Only the current result is shown — no history or side-by-side comparison.

Regex Tester reads "Pattern", "Flags" and "Test text" from the form above and writes the answer into the results panel. There is no account, no upload and no server round-trip: the JavaScript on this page does the work on your own device.

How to use Regex Tester

  1. Open Regex Tester from Text & Code, or find it with the search box in the header.
  2. Fill in the fields shown above: "Pattern", "Flags" and "Test text".
  3. Press Test. The result replaces whatever was shown before; only the current run is displayed, never two results side by side.
  4. Use Copy to put the result on your clipboard. A message appears only when something was actually copied.

A worked example

The form opens with these values: Pattern = \b[a-z]+@[a-z]+\.[a-z]{2,}\b; Flags = gi. Press Test once to see how the output is laid out, then replace them with your own data and press again — the new result replaces the old one.

Frequently asked questions

Is what I type uploaded anywhere?

No. Regex Tester processes "Pattern", "Flags" and "Test text" with JavaScript inside your browser. Your inputs and the result stay on your device; Utilixo keeps no copy of them.

Can I keep several results to compare?

No. Each press of Test rebuilds the result from the current inputs and overwrites the previous one. To compare runs, note the earlier result down yourself.

Anything specific to watch with Regex Tester?

The result depends only on the fields shown above ("Pattern", "Flags" and "Test text"); change one of them and press Test again to get an updated answer.

How do I take the result away?

Press Copy after a result appears. The copy button only reports success when there is content to copy.

Do I need to sign up or pay?

No. Regex Tester is free, needs no registration and has no usage limit. Open the page and use it.
