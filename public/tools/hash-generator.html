About Hash Generator

Generate MD5, SHA-1, SHA-256 and SHA-512 checksums locally. Press Generate hashes to see the result in the results panel. Everything runs locally in your browser; nothing is uploaded. Only the current result is shown — no history or side-by-side comparison.

Hash Generator reads “Text to hash” from the form above and writes the answer into the results panel — Computing…. There is no account, no upload and no server round-trip: the JavaScript on this page does the work on your own device.

How to use Hash Generator

  1. Open Hash Generator from Text & Code, or find it with the search box in the header.
  2. Fill in the fields shown above: “Text to hash”.
  3. Press Generate hashes. The result replaces whatever was shown before; only the current run is displayed, never two results side by side.
  4. Use Copy to put the result on your clipboard. A message appears only when something was actually copied.

A worked example

Enter your own values in the fields above and press Generate hashes. Change any input and press again; the result is recalculated from the current inputs and replaces the previous one.
