Sobre Conversor YAML ↔ JSON

Converta YAML para JSON e JSON para YAML. Clique em Converter; o resultado aparece no painel de resultados. Tudo corre localmente no navegador, nada é enviado. Apenas o resultado atual é mostrado — sem histórico nem comparação lado a lado.

Conversor YAML ↔ JSON lê as entradas do formulário e escreve a resposta no painel de resultados — Suporta o subconjunto comum: mappings, sequências, escalares, booleanos, números e null. Âncoras, aliases e fluxos multi-documento não são suportados. Não há conta nem envio ao servidor: o JavaScript da página trabalha no seu dispositivo.

Como usar esta ferramenta

  1. Abra Conversor YAML ↔ JSON pela categoria Conversores ou encontre-o com a caixa de pesquisa no topo.
  2. Clique em Converter. O novo resultado substitui o anterior; só a execução atual é mostrada, nunca dois resultados lado a lado.
  3. Use Copiar saída para copiar o resultado. A mensagem só aparece quando há conteúdo copiado.

Exemplo prático

Introduza os seus valores nos campos e clique em Converter. Após qualquer alteração, um novo clique recalcula com os dados atuais e substitui o resultado anterior.

Perguntas frequentes

Os meus dados são enviados?

Não. Conversor YAML ↔ JSON processa as entradas com JavaScript no navegador. Entradas e resultado ficam no seu dispositivo; o Utilixo não guarda cópias.

Posso comparar vários resultados?

Não lado a lado. Cada clique em Converter recalcula com as entradas atuais e substitui o resultado anterior. Anote você os valores anteriores.

Há algo específico no Conversor YAML ↔ JSON?

Suporta o subconjunto comum: mappings, sequências, escalares, booleanos, números e null. Âncoras, aliases e fluxos multi-documento não são suportados.

Como levo o resultado?

Depois de ver o resultado, clique em Copiar saída. Com resultado vazio não aparece aviso de sucesso.

Preciso de registo ou de pagar?

Não. Conversor YAML ↔ JSON é grátis, sem registo e sem limite. Abra a página e use.
