Gerador de Box-Shadow CSS

Sombras em camadas com prévia ao vivo e CSS pronto. Introduza os valores e clique no botão para ver o resultado.

Sobre Gerador de Box-Shadow CSS

Sombras em camadas com prévia ao vivo e CSS pronto. Clique em Gerar; o resultado aparece no painel de resultados. Tudo corre localmente no navegador, nada é enviado. Apenas o resultado atual é mostrado — sem histórico nem comparação lado a lado.

Gerador de Box-Shadow CSS lê «Deslocamento X», «Deslocamento Y», «Desfoque», «Expansão», «Cor» e «Opacidade» do formulário e escreve a resposta no painel de resultados. Não há conta nem envio ao servidor: o JavaScript da página trabalha no seu dispositivo.

Como usar esta ferramenta

  1. Abra Gerador de Box-Shadow CSS pela categoria Geradores e utilitários ou encontre-o com a caixa de pesquisa no topo.
  2. Preencha os campos mostrados: «Deslocamento X», «Deslocamento Y», «Desfoque», «Expansão», «Cor» e «Opacidade».
  3. Clique em Gerar. O novo resultado substitui o anterior; só a execução atual é mostrada, nunca dois resultados lado a lado.
  4. Use Copiar CSS para copiar o resultado. A mensagem só aparece quando há conteúdo copiado.

Exemplo prático

Introduza os seus valores nos campos e clique em Gerar. Após qualquer alteração, um novo clique recalcula com os dados atuais e substitui o resultado anterior.

Perguntas frequentes

Os meus dados são enviados?

Não. Gerador de Box-Shadow CSS processa «Deslocamento X», «Deslocamento Y», «Desfoque», «Expansão», «Cor» e «Opacidade» com JavaScript no navegador. Entradas e resultado ficam no seu dispositivo; o Utilixo não guarda cópias.

Posso comparar vários resultados?

Não lado a lado. Cada clique em Gerar recalcula com as entradas atuais e substitui o resultado anterior. Anote você os valores anteriores.

Há algo específico no Gerador de Box-Shadow CSS?

O resultado depende apenas dos campos visíveis («Deslocamento X», «Deslocamento Y», «Desfoque», «Expansão», «Cor» e «Opacidade»); altere um e clique em Gerar novamente.

Como levo o resultado?

Depois de ver o resultado, clique em Copiar CSS. Com resultado vazio não aparece aviso de sucesso.

Preciso de registo ou de pagar?

Não. Gerador de Box-Shadow CSS é grátis, sem registo e sem limite. Abra a página e use.
