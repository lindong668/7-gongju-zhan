Sobre JSON para TypeScript

Gere interfaces TS a partir de qualquer exemplo JSON. Clique em Gerar; o resultado aparece no painel de resultados. Tudo corre localmente no navegador, nada é enviado. Apenas o resultado atual é mostrado — sem histórico nem comparação lado a lado.

JSON para TypeScript lê «Cole o JSON» e «Nome da interface raiz» do formulário e escreve a resposta no painel de resultados. Não há conta nem envio ao servidor: o JavaScript da página trabalha no seu dispositivo.

Como usar esta ferramenta

  1. Abra JSON para TypeScript pela categoria Texto e código ou encontre-o com a caixa de pesquisa no topo.
  2. Preencha os campos mostrados: «Cole o JSON» e «Nome da interface raiz».
  3. Clique em Gerar. O novo resultado substitui o anterior; só a execução atual é mostrada, nunca dois resultados lado a lado.
  4. Use Copiar para copiar o resultado. A mensagem só aparece quando há conteúdo copiado.

Exemplo prático

Ao abrir, estes valores já estão definidos: Nome da interface raiz = Root. Clique uma vez em Gerar para ver o formato do resultado, substitua pelos seus dados e clique de novo: o resultado novo substitui o antigo.

Perguntas frequentes

Os meus dados são enviados?

Não. JSON para TypeScript processa «Cole o JSON» e «Nome da interface raiz» com JavaScript no navegador. Entradas e resultado ficam no seu dispositivo; o Utilixo não guarda cópias.

Posso comparar vários resultados?

Não lado a lado. Cada clique em Gerar recalcula com as entradas atuais e substitui o resultado anterior. Anote você os valores anteriores.

Há algo específico no JSON para TypeScript?

O resultado depende apenas dos campos visíveis («Cole o JSON» e «Nome da interface raiz»); altere um e clique em Gerar novamente.

Como levo o resultado?

Depois de ver o resultado, clique em Copiar. Com resultado vazio não aparece aviso de sucesso.

Preciso de registo ou de pagar?

Não. JSON para TypeScript é grátis, sem registo e sem limite. Abra a página e use.
