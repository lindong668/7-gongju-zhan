Gerador de Hash

Checksums MD5, SHA-1, SHA-256 e SHA-512. Introduza os valores e clique no botão para ver o resultado.

Sobre Gerador de Hash

Checksums MD5, SHA-1, SHA-256 e SHA-512. Clique em Gerar hashes; o resultado aparece no painel de resultados. Tudo corre localmente no navegador, nada é enviado. Apenas o resultado atual é mostrado — sem histórico nem comparação lado a lado.

Gerador de Hash lê “Texto para o hash” do formulário e escreve a resposta no painel de resultados — A calcular…. Não há conta nem envio ao servidor: o JavaScript da página trabalha no seu dispositivo.

Como usar esta ferramenta

  1. Abra Gerador de Hash pela categoria Texto e código ou encontre-o com a caixa de pesquisa no topo.
  2. Preencha os campos mostrados: “Texto para o hash”.
  3. Clique em Gerar hashes. O novo resultado substitui o anterior; só a execução atual é mostrada, nunca dois resultados lado a lado.
  4. Use Copiar para copiar o resultado. A mensagem só aparece quando há conteúdo copiado.

Exemplo prático

Introduza os seus valores nos campos e clique em Gerar hashes. Após qualquer alteração, um novo clique recalcula com os dados atuais e substitui o resultado anterior.

Perguntas frequentes

Os meus dados são enviados?

Não. Gerador de Hash processa “Texto para o hash” com JavaScript no navegador. Entradas e resultado ficam no seu dispositivo; o Utilixo não guarda cópias.

Posso comparar vários resultados?

Não lado a lado. Cada clique em Gerar hashes recalcula com as entradas atuais e substitui o resultado anterior. Anote você os valores anteriores.

Há algo específico no Gerador de Hash?

A calcular…

Como levo o resultado?

Depois de ver o resultado, clique em Copiar. Com resultado vazio não aparece aviso de sucesso.

Preciso de registo ou de pagar?

Não. Gerador de Hash é grátis, sem registo e sem limite. Abra a página e use.
