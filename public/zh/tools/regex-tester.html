关于正则表达式测试工具

实时测试 JavaScript 正则表达式的匹配结果。填写“表达式”、“修饰符”、“待测试文本”后点「测试」，结果会显示在结果区；运算全部在浏览器本地完成，输入内容不会上传。

正则表达式测试工具 读取上方表单里的“表达式”、“修饰符”、“待测试文本”，把答案写进结果区。页面不需要登录，也不会把数据发到服务器：所有计算都由本页的脚本在你的设备上完成。

如何使用

  1. 从文本与代码分类打开正则表达式测试工具，也可以用页头的搜索框找到它。
  2. 按页面上的字段逐一填写：“表达式”、“修饰符”、“待测试文本”。
  3. 点「测试」。新结果会覆盖上一次的结果，页面只显示当前这一轮，不会把两次结果并排放在一起。
  4. 点「复制」把结果复制到剪贴板；只有真的复制到内容时才会出现成功提示。

使用示例

页面打开时这几个字段已有默认值：表达式 = \b[a-z]+@[a-z]+\.[a-z]{2,}\b、修饰符 = gi。先点一次「测试」看看结果长什么样，再换成自己的数据重新点一次，新结果会替换旧结果。

常见问题

我输入的内容会被上传吗？

不会。正则表达式测试工具 用浏览器里的脚本处理“表达式”、“修饰符”、“待测试文本”，输入和结果都留在你的设备上，Utilixo 不保存副本。

能不能保留多次结果做对比？

不能并排保留。每次点「测试」都会按当前输入重算并覆盖上一次结果；想对比请自己先记下前一次的数值。

用正则表达式测试工具时要注意什么？

结果只取决于页面上这几个字段（“表达式”、“修饰符”、“待测试文本”）；改动其中任意一项，再点「测试」就会得到更新后的结果。

结果怎么带走？

结果出现后点「复制」即可复制；结果为空时不会出现成功提示。

需要注册或付费吗？

不需要。正则表达式测试工具 免费、无需注册，也没有次数限制，打开页面直接用。
