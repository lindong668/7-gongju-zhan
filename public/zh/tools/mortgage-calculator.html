关于房贷计算器

计算月供，并含房产税、保险与房贷险。填写“房屋总价”、“首付”、“利率（APR %）”后点「计算」，结果会显示在结果区；运算全部在浏览器本地完成，输入内容不会上传。

房贷计算器 读取上方表单里的“房屋总价”、“首付”、“利率（APR %）”、“期限（年）”、“房产税 / 年”、“房屋保险 / 年”，把答案写进结果区，'+msg+'。页面不需要登录，也不会把数据发到服务器：所有计算都由本页的脚本在你的设备上完成。

如何使用

  1. 从财务计算分类打开房贷计算器，也可以用页头的搜索框找到它。
  2. 按页面上的字段逐一填写：“房屋总价”、“首付”、“利率（APR %）”、“期限（年）”、“房产税 / 年”、“房屋保险 / 年”。
  3. 点「计算」。新结果会覆盖上一次的结果，页面只显示当前这一轮，不会把两次结果并排放在一起。
  4. 点「复制」把结果复制到剪贴板；只有真的复制到内容时才会出现成功提示。

使用示例

页面打开时这几个字段已有默认值：房屋总价 = 400000、首付 = 80000、利率（APR %） = 6.5、期限（年） = 30。先点一次「计算」看看结果长什么样，再换成自己的数据重新点一次，新结果会替换旧结果。

常见问题

我输入的内容会被上传吗？

不会。房贷计算器 用浏览器里的脚本处理“房屋总价”、“首付”、“利率（APR %）”、“期限（年）”、“房产税 / 年”、“房屋保险 / 年”，输入和结果都留在你的设备上，Utilixo 不保存副本。

能不能保留多次结果做对比？

不能并排保留。每次点「计算」都会按当前输入重算并覆盖上一次结果；想对比请自己先记下前一次的数值。
