关于Markdown 转 HTML

在浏览器中把 Markdown 转换为整洁的 HTML。填写“Markdown”后点「转换」，结果会显示在结果区；运算全部在浏览器本地完成，输入内容不会上传。

Markdown 转 HTML 读取上方表单里的“Markdown”，把答案写进结果区。页面不需要登录，也不会把数据发到服务器：所有计算都由本页的脚本在你的设备上完成。

如何使用

  1. 从文本与代码分类打开Markdown 转 HTML，也可以用页头的搜索框找到它。
  2. 按页面上的字段逐一填写：“Markdown”。
  3. 点「转换」。新结果会覆盖上一次的结果，页面只显示当前这一轮，不会把两次结果并排放在一起。
  4. 点「复制 HTML」把结果复制到剪贴板；只有真的复制到内容时才会出现成功提示。

常见问题

我输入的内容会被上传吗？

不会。Markdown 转 HTML 用浏览器里的脚本处理“Markdown”，输入和结果都留在你的设备上，Utilixo 不保存副本。

能不能保留多次结果做对比？

不能并排保留。每次点「转换」都会按当前输入重算并覆盖上一次结果；想对比请自己先记下前一次的数值。

用Markdown 转 HTML时要注意什么？

结果只取决于页面上这几个字段（“Markdown”）；改动其中任意一项，再点「转换」就会得到更新后的结果。

结果怎么带走？

结果出现后点「复制 HTML」即可复制；结果为空时不会出现成功提示。

需要注册或付费吗？

不需要。Markdown 转 HTML 免费、无需注册，也没有次数限制，打开页面直接用。
