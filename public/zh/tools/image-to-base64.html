关于图片转 Base64

把图片转成可内联进 CSS 的 Base64 数据。填写“选择图片”后点「转换为 Base64」，结果会显示在结果区；运算全部在浏览器本地完成，输入内容不会上传。

图片转 Base64 读取上方表单里的“选择图片”，把答案写进结果区，Base64 编码后体积约比原文件大 33%，小图标没问题，照片就太浪费了。图片不会离开你的浏览器。页面不需要登录，也不会把数据发到服务器：所有计算都由本页的脚本在你的设备上完成。

如何使用

  1. 从单位换算分类打开图片转 Base64，也可以用页头的搜索框找到它。
  2. 按页面上的字段逐一填写：“选择图片”。
  3. 点「转换为 Base64」。新结果会覆盖上一次的结果，页面只显示当前这一轮，不会把两次结果并排放在一起。
  4. 点「复制 Data URI」把结果复制到剪贴板；只有真的复制到内容时才会出现成功提示。

常见问题

我输入的内容会被上传吗？

不会。图片转 Base64 用浏览器里的脚本处理“选择图片”，输入和结果都留在你的设备上，Utilixo 不保存副本。

能不能保留多次结果做对比？

不能并排保留。每次点「转换为 Base64」都会按当前输入重算并覆盖上一次结果；想对比请自己先记下前一次的数值。

用图片转 Base64时要注意什么？

Base64 编码后体积约比原文件大 33%，小图标没问题，照片就太浪费了。图片不会离开你的浏览器。

结果怎么带走？

结果出现后点「复制 Data URI」即可复制；结果为空时不会出现成功提示。

需要注册或付费吗？

不需要。图片转 Base64 免费、无需注册，也没有次数限制，打开页面直接用。
