サイコロシミュレーターについて

任意の個数・任意の面数のサイコロを振る。「サイコロの個数」・「1個あたりの面数」・「修正値」を入力して「振る」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

サイコロシミュレーターは上のフォームの「サイコロの個数」・「1個あたりの面数」・「修正値」を読み取り、結果パネルへ答えを書き出します。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 生成とユーティリティカテゴリからサイコロシミュレーターを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「サイコロの個数」・「1個あたりの面数」・「修正値」。
  3. 「振る」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は サイコロの個数 = 2、修正値 = 0 です。まず「振る」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。サイコロシミュレーターは「サイコロの個数」・「1個あたりの面数」・「修正値」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「振る」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

サイコロシミュレーターで気を付けることは？

結果はページ上の項目（「サイコロの個数」・「1個あたりの面数」・「修正値」）だけで決まります。いずれかを変えて「振る」を押し直すと更新されます。

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。サイコロシミュレーターは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
