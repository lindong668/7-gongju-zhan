文字数・単語数カウンターについて

単語数、文字数、文数、読了時間をカウント。“テキストを貼り付けまたは入力”を入力して「計算」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

文字数・単語数カウンターは上のフォームの“テキストを貼り付けまたは入力”を読み取り、結果パネルへ答えを書き出します，読了時間は1分あたり200語として計算しています。入力と同時に集計されます。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. テキストとコードカテゴリから文字数・単語数カウンターを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：“テキストを貼り付けまたは入力”。
  3. 「計算」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

上の項目に自分のデータを入力し、「計算」を押すと結果が出ます。入力を変えてもう一度押すと、現在の入力で再計算され前の結果を置き換えます。

よくある質問

入力した内容は送信されますか？

いいえ。文字数・単語数カウンターは“テキストを貼り付けまたは入力”をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「計算」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

文字数・単語数カウンターで気を付けることは？

読了時間は1分あたり200語として計算しています。入力と同時に集計されます。

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。文字数・単語数カウンターは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
