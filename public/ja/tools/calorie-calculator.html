カロリー・TDEE計算ツールについて

維持・減量・増量に必要な1日のカロリー。「性別」・「年齢」・「身長（cm）」を入力して「計算」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

カロリー・TDEE計算ツールは上のフォームの「性別」・「年齢」・「身長（cm）」・「体重（kg）」・「活動レベル」を読み取り、結果パネルへ答えを書き出します，BMR は Mifflin-St Jeor 式を使用します：男性 10×体重(kg) + 6.25×身長(cm) − 5×年齢 + 5、女性はそこから 161 を引きます。1 日 500 kcal の赤字は週約 0.5 kg の減量に相当します。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 健康と暮らしカテゴリからカロリー・TDEE計算ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「性別」・「年齢」・「身長（cm）」・「体重（kg）」・「活動レベル」。
  3. 「計算」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は 年齢 = 32、身長（cm） = 175、体重（kg） = 75 です。まず「計算」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。カロリー・TDEE計算ツールは「性別」・「年齢」・「身長（cm）」・「体重（kg）」・「活動レベル」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「計算」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

カロリー・TDEE計算ツールで気を付けることは？

BMR は Mifflin-St Jeor 式を使用します：男性 10×体重(kg) + 6.25×身長(cm) − 5×年齢 + 5、女性はそこから 161 を引きます。1 日 500 kcal の赤字は週約 0.5 kg の減量に相当します。

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。カロリー・TDEE計算ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
