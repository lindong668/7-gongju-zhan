画像をBase64に変換について

画像をインラインCSS用のBase64データURIに。“画像を選択”を入力して「Base64 に変換」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

画像をBase64に変換は上のフォームの“画像を選択”を読み取り、結果パネルへ答えを書き出します，Base64は元ファイルより約33%大きくなります。小さなアイコンには向きますが、写真には不向きです。画像がブラウザの外に出ることはありません。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 単位変換カテゴリから画像をBase64に変換を開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：“画像を選択”。
  3. 「Base64 に変換」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「Data URIをコピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

上の項目に自分のデータを入力し、「Base64 に変換」を押すと結果が出ます。入力を変えてもう一度押すと、現在の入力で再計算され前の結果を置き換えます。

よくある質問

入力した内容は送信されますか？

いいえ。画像をBase64に変換は“画像を選択”をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「Base64 に変換」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

画像をBase64に変換で気を付けることは？

Base64は元ファイルより約33%大きくなります。小さなアイコンには向きますが、写真には不向きです。画像がブラウザの外に出ることはありません。

結果を持ち出すには？

結果が出たら「Data URIをコピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。画像をBase64に変換は無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
