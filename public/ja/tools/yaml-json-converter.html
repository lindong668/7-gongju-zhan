YAML⇔JSON変換ツール

YAMLをJSONに、JSONをYAMLに変換。項目を入力してボタンを押すと結果が表示されます。

一般的な構文に対応しています：マッピング、シーケンス、スカラー、真偽値、数値、null。アンカー、エイリアス、複数ドキュメントには対応していません。

YAML⇔JSON変換ツールについて

YAMLをJSONに、JSONをYAMLに変換。「変換」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

YAML⇔JSON変換ツールは上のフォームの入力内容を読み取り、結果パネルへ答えを書き出します。一般的な構文に対応しています：マッピング、シーケンス、スカラー、真偽値、数値、null。アンカー、エイリアス、複数ドキュメントには対応していません。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 単位変換カテゴリからYAML⇔JSON変換ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. 「変換」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  3. 「出力をコピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

上の項目に自分のデータを入力し、「変換」を押すと結果が出ます。入力を変えてもう一度押すと、現在の入力で再計算され前の結果を置き換えます。

よくある質問

入力した内容は送信されますか？

いいえ。YAML⇔JSON変換ツールは入力内容をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「変換」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

YAML⇔JSON変換ツールで気を付けることは？

一般的な構文に対応しています：マッピング、シーケンス、スカラー、真偽値、数値、null。アンカー、エイリアス、複数ドキュメントには対応していません。

結果を持ち出すには？

結果が出たら「出力をコピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。YAML⇔JSON変換ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
