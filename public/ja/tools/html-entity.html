HTMLエンティティ変換

HTMLエンティティを安全にエスケープ・復号。項目を入力してボタンを押すと結果が表示されます。

HTMLエンティティ変換について

HTMLエンティティを安全にエスケープ・復号。“テキスト”を入力して「エスケープ →」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

HTMLエンティティ変換は上のフォームの“テキスト”を読み取り、結果パネルへ答えを書き出します。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. テキストとコードカテゴリからHTMLエンティティ変換を開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：“テキスト”。
  3. 「エスケープ →」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

上の項目に自分のデータを入力し、「エスケープ →」を押すと結果が出ます。入力を変えてもう一度押すと、現在の入力で再計算され前の結果を置き換えます。

よくある質問

入力した内容は送信されますか？

いいえ。HTMLエンティティ変換は“テキスト”をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「エスケープ →」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

HTMLエンティティ変換で気を付けることは？

結果はページ上の項目（“テキスト”）だけで決まります。いずれかを変えて「エスケープ →」を押し直すと更新されます。

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。HTMLエンティティ変換は無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
