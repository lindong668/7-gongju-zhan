BMI計算ツール

メートル法・ヤードポンド法対応、判定付き。項目を入力してボタンを押すと結果が表示されます。

BMI計算ツールについて

メートル法・ヤードポンド法対応、判定付き。「単位」・「体重（kg）」・「身長（cm）」を入力して「計算」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

BMI計算ツールは上のフォームの「単位」・「体重（kg）」・「身長（cm）」・「体重（lb）」・「身長（フィート）」・「身長（インチ）」を読み取り、結果パネルへ答えを書き出します，BMIはあくまで目安であり、診断ではありません。筋肉と脂肪は区別されません。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 健康と暮らしカテゴリからBMI計算ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「単位」・「体重（kg）」・「身長（cm）」・「体重（lb）」・「身長（フィート）」・「身長（インチ）」。
  3. 「計算」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は 体重（kg） = 72、身長（cm） = 175、体重（lb） = 160、身長（フィート） = 5 です。まず「計算」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。BMI計算ツールは「単位」・「体重（kg）」・「身長（cm）」・「体重（lb）」・「身長（フィート）」・「身長（インチ）」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「計算」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

BMI計算ツールで気を付けることは？

BMIはあくまで目安であり、診断ではありません。筋肉と脂肪は区別されません。

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。BMI計算ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
