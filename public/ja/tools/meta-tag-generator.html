メタタグ生成ツール

SEO、Open Graph、Twitterカードのタグを作成。項目を入力してボタンを押すと結果が表示されます。

メタタグ生成ツールについて

SEO、Open Graph、Twitterカードのタグを作成。「ページタイトル」・「説明」・「canonical URL」を入力して「生成」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

メタタグ生成ツールは上のフォームの「ページタイトル」・「説明」・「canonical URL」・「画像 URL」・「サイト名」・「Twitter アカウント」を読み取り、結果パネルへ答えを書き出します。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 生成とユーティリティカテゴリからメタタグ生成ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「ページタイトル」・「説明」・「canonical URL」・「画像 URL」・「サイト名」・「Twitter アカウント」。
  3. 「生成」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「HTMLをコピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は ページタイトル = Percentage Calculator — Three Modes、説明 = 3 つのモードでパーセントを計算。パーセントとパーセントポイントの違いにも対応。、canonical URL = https://example.com/percentage-calculator、画像 URL = https://example.com/og-cover.png です。まず「生成」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。メタタグ生成ツールは「ページタイトル」・「説明」・「canonical URL」・「画像 URL」・「サイト名」・「Twitter アカウント」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「生成」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

メタタグ生成ツールで気を付けることは？

結果はページ上の項目（「ページタイトル」・「説明」・「canonical URL」・「画像 URL」・「サイト名」・「Twitter アカウント」）だけで決まります。いずれかを変えて「生成」を押し直すと更新されます。

結果を持ち出すには？

結果が出たら「HTMLをコピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。メタタグ生成ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
