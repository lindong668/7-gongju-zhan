画像圧縮ツールについて

JPEG、PNG、WebPをブラウザ上で直接圧縮。「画像を選択」・「品質」・「最大幅（px）」を入力して「計算」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

画像圧縮ツールは上のフォームの「画像を選択」・「品質」・「最大幅（px）」・「出力形式」を読み取り、結果パネルへ答えを書き出します，'+w+'×'+h+' px · '+icSize(blob.size)+'。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 生成とユーティリティカテゴリから画像圧縮ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「画像を選択」・「品質」・「最大幅（px）」・「出力形式」。
  3. 「計算」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は 最大幅（px） = 1600 です。まず「計算」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。画像圧縮ツールは「画像を選択」・「品質」・「最大幅（px）」・「出力形式」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「計算」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

画像圧縮ツールで気を付けることは？

'+w+'×'+h+' px · '+icSize(blob.size)+'

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。画像圧縮ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
