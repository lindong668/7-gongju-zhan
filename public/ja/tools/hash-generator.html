ハッシュ生成ツール

MD5、SHA-1、SHA-256、SHA-512のチェックサム。項目を入力してボタンを押すと結果が表示されます。

ハッシュ生成ツールについて

MD5、SHA-1、SHA-256、SHA-512のチェックサム。“ハッシュ化するテキスト”を入力して「ハッシュを生成」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

ハッシュ生成ツールは上のフォームの“ハッシュ化するテキスト”を読み取り、結果パネルへ答えを書き出します，計算中…。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. テキストとコードカテゴリからハッシュ生成ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：“ハッシュ化するテキスト”。
  3. 「ハッシュを生成」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

上の項目に自分のデータを入力し、「ハッシュを生成」を押すと結果が出ます。入力を変えてもう一度押すと、現在の入力で再計算され前の結果を置き換えます。

よくある質問

入力した内容は送信されますか？

いいえ。ハッシュ生成ツールは“ハッシュ化するテキスト”をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「ハッシュを生成」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

ハッシュ生成ツールで気を付けることは？

計算中…

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。ハッシュ生成ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
