住宅ローン電卓について

月々の返済額に固定資産税・保険・PMIを含めて計算。「物件価格」・「頭金」・「金利（APR %）」を入力して「計算」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

住宅ローン電卓は上のフォームの「物件価格」・「頭金」・「金利（APR %）」・「期間（年）」・「固定資産税 / 年」・「保険料 / 年」を読み取り、結果パネルへ答えを書き出します，'+msg+'。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 家計・金融計算カテゴリから住宅ローン電卓を開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「物件価格」・「頭金」・「金利（APR %）」・「期間（年）」・「固定資産税 / 年」・「保険料 / 年」。
  3. 「計算」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「コピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は 物件価格 = 400000、頭金 = 80000、金利（APR %） = 6.5、期間（年） = 30 です。まず「計算」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。住宅ローン電卓は「物件価格」・「頭金」・「金利（APR %）」・「期間（年）」・「固定資産税 / 年」・「保険料 / 年」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「計算」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

住宅ローン電卓で気を付けることは？

'+msg+'

結果を持ち出すには？

結果が出たら「コピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。住宅ローン電卓は無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
