カラー変換ツールについて

HEX、RGB、HSLを相互変換、プレビュー付き。「HEX」・「R（赤）」・「G（緑）」を入力して「変換」を押すと結果パネルに表示されます。処理はブラウザ内で完結し、入力内容は送信されません。

カラー変換ツールは上のフォームの「HEX」・「R（赤）」・「G（緑）」・「B（青）」を読み取り、結果パネルへ答えを書き出します。ログインやサーバーへの送信は不要で、ページ内の JavaScript が端末上で処理します。

使い方

  1. 単位変換カテゴリからカラー変換ツールを開くか、ヘッダーの検索ボックスで探してください。
  2. ページの項目を入力します：「HEX」・「R（赤）」・「G（緑）」・「B（青）」。
  3. 「変換」を押します。新しい結果が前回の結果を上書きし、表示されるのは常に現在の 1 回分だけで、2 つが並ぶことはありません。
  4. 「HEXをコピー」で結果をクリップボードへコピーできます。実際にコピーできたときだけメッセージが出ます。

使用例

開いたときの初期値は HEX = #6366F1、R（赤） = 99、G（緑） = 102、B（青） = 241 です。まず「変換」を 1 回押して出力の形を確認し、自分のデータに差し替えてもう一度押すと、結果が新しい値で更新されます。

よくある質問

入力した内容は送信されますか？

いいえ。カラー変換ツールは「HEX」・「R（赤）」・「G（緑）」・「B（青）」をブラウザ内の JavaScript で処理します。入力と結果は端末内に残り、Utilixoで複製は保存されません。

複数回の結果を並べて比較できますか？

できません。「変換」を押すたびに現在の入力で再計算され、前の結果を上書きします。比較したい場合は前回の値を控えてください。

カラー変換ツールで気を付けることは？

結果はページ上の項目（「HEX」・「R（赤）」・「G（緑）」・「B（青）」）だけで決まります。いずれかを変えて「変換」を押し直すと更新されます。

結果を持ち出すには？

結果が出たら「HEXをコピー」を押してください。空の結果では成功メッセージは出ません。

登録や料金は必要ですか？

不要です。カラー変換ツールは無料・登録不要・回数制限なしで、ページを開けばすぐ使えます。
