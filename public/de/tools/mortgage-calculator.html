Über Hypothekenrechner

Monatsrate plus Grundsteuer, Versicherung und PMI. Berechnen drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

Hypothekenrechner liest „Kaufpreis“, „Anzahlung“, „Zinssatz (% APR)“, „Laufzeit (Jahre)“, „Grundsteuer / Jahr“ und „Versicherung / Jahr“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld — '+msg+'. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Hypothekenrechner über die Kategorie Finanzen oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „Kaufpreis“, „Anzahlung“, „Zinssatz (% APR)“, „Laufzeit (Jahre)“, „Grundsteuer / Jahr“ und „Versicherung / Jahr“.
  3. Drücken Sie Berechnen. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: Kaufpreis = 400000; Anzahlung = 80000; Zinssatz (% APR) = 6.5; Laufzeit (Jahre) = 30. Drücken Sie Berechnen einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Hypothekenrechner verarbeitet „Kaufpreis“, „Anzahlung“, „Zinssatz (% APR)“, „Laufzeit (Jahre)“, „Grundsteuer / Jahr“ und „Versicherung / Jahr“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Berechnen berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Hypothekenrechner ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
