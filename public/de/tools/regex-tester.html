Regex-Tester

JavaScript-Reguläre Ausdrücke mit Live-Treffern testen. Werte eingeben und die Schaltfläche drücken, um das Ergebnis zu sehen.

Über Regex-Tester

JavaScript-Reguläre Ausdrücke mit Live-Treffern testen. Testen drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

Regex-Tester liest „Muster“, „Flags“ und „Testtext“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Regex-Tester über die Kategorie Text & Code oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „Muster“, „Flags“ und „Testtext“.
  3. Drücken Sie Testen. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: Muster = \b[a-z]+@[a-z]+\.[a-z]{2,}\b; Flags = gi. Drücken Sie Testen einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Regex-Tester verarbeitet „Muster“, „Flags“ und „Testtext“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Testen berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei Regex-Tester zu beachten?

Das Ergebnis hängt nur von den angezeigten Feldern ab („Muster“, „Flags“ und „Testtext“); ändern Sie eines und drücken Sie Testen erneut.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Regex-Tester ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
