Über JSON zu TypeScript

TS-Interfaces aus jedem JSON-Beispiel erzeugen. Erzeugen drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

JSON zu TypeScript liest „JSON einfügen“ und „Name des Wurzel-Interfaces“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie JSON zu TypeScript über die Kategorie Text & Code oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „JSON einfügen“ und „Name des Wurzel-Interfaces“.
  3. Drücken Sie Erzeugen. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: Name des Wurzel-Interfaces = Root. Drücken Sie Erzeugen einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. JSON zu TypeScript verarbeitet „JSON einfügen“ und „Name des Wurzel-Interfaces“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Erzeugen berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei JSON zu TypeScript zu beachten?

Das Ergebnis hängt nur von den angezeigten Feldern ab („JSON einfügen“ und „Name des Wurzel-Interfaces“); ändern Sie eines und drücken Sie Erzeugen erneut.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. JSON zu TypeScript ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
