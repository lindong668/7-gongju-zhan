Text-Vergleich

Zwei Textblöcke zeichenweise vergleichen und hinzugefügte sowie entfernte Stellen hervorheben. Werte eingeben und die Schaltfläche drücken, um das Ergebnis zu sehen.

Über Text-Vergleich

Zwei Textblöcke zeichenweise vergleichen und hinzugefügte sowie entfernte Stellen hervorheben. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

Text-Vergleich liest „Original“ und „Geändert“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld — '+U.hint+'. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Text-Vergleich über die Kategorie Text & Code oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „Original“ und „Geändert“.
  3. Drücken Sie Vergleichen. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Geben Sie Ihre Werte in die Felder ein und drücken Sie Vergleichen. Nach einer Änderung wird bei jedem Drücken neu aus den aktuellen Eingaben gerechnet und das vorherige Ergebnis ersetzt.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Text-Vergleich verarbeitet „Original“ und „Geändert“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Vergleichen berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei Text-Vergleich zu beachten?

'+U.hint+'

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Text-Vergleich ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
