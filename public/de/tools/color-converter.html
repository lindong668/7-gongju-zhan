Über Farb-Umrechner

HEX, RGB und HSL mit Live-Vorschau. Umwandeln drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen.

Farb-Umrechner liest „HEX“, „R (Rot)“, „G (Grün)“ und „B (Blau)“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Farb-Umrechner über die Kategorie Umrechner oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „HEX“, „R (Rot)“, „G (Grün)“ und „B (Blau)“.
  3. Drücken Sie Umwandeln. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit HEX kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: HEX = #6366F1; R (Rot) = 99; G (Grün) = 102; B (Blau) = 241. Drücken Sie Umwandeln einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Farb-Umrechner verarbeitet „HEX“, „R (Rot)“, „G (Grün)“ und „B (Blau)“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Umwandeln berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei Farb-Umrechner zu beachten?

Das Ergebnis hängt nur von den angezeigten Feldern ab („HEX“, „R (Rot)“, „G (Grün)“ und „B (Blau)“); ändern Sie eines und drücken Sie Umwandeln erneut.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis HEX kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Farb-Umrechner ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
