JWT-Decoder

Header und Payload eines JWT entschlüsseln, ohne es irgendwohin zu senden.

This tool only decodes. It never verifies the signature and never sends your token anywhere — but a JWT is still a credential, so avoid pasting production tokens into any website you do not control.
