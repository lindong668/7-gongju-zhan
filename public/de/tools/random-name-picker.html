Über Zufalls-Namensrad

Drehen Sie das Rad für eine faire Auswahl mit echter Animation. Rad drehen drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

Zufalls-Namensrad liest „Namen (einer pro Zeile)“ und „Drehdauer (s)“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld — Zur Fairness: Das Rad wählt gleichverteilt mit kryptografischem Zufall. Die Animation ist nur Dekoration — die Entscheidung fällt, bevor sie startet. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Zufalls-Namensrad über die Kategorie Generatoren & Hilfsmittel oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „Namen (einer pro Zeile)“ und „Drehdauer (s)“.
  3. Drücken Sie Rad drehen. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: Drehdauer (s) = 4. Drücken Sie Rad drehen einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Zufalls-Namensrad verarbeitet „Namen (einer pro Zeile)“ und „Drehdauer (s)“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Rad drehen berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei Zufalls-Namensrad zu beachten?

Zur Fairness: Das Rad wählt gleichverteilt mit kryptografischem Zufall. Die Animation ist nur Dekoration — die Entscheidung fällt, bevor sie startet.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Zufalls-Namensrad ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
