Über URL-Kodierer / -Dekodierer

URL-Komponenten prozentual kodieren und dekodieren. Kodieren drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

URL-Kodierer / -Dekodierer liest “Text oder URL” aus dem Formular und schreibt die Antwort ins Ergebnisfeld — URL kodieren behält die Struktur (/, :, &, =). Komponente kodieren maskiert alles – nimm das für einzelne Abfragewerte. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie URL-Kodierer / -Dekodierer über die Kategorie Text & Code oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: “Text oder URL”.
  3. Drücken Sie Kodieren. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Geben Sie Ihre Werte in die Felder ein und drücken Sie Kodieren. Nach einer Änderung wird bei jedem Drücken neu aus den aktuellen Eingaben gerechnet und das vorherige Ergebnis ersetzt.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. URL-Kodierer / -Dekodierer verarbeitet “Text oder URL” mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Kodieren berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei URL-Kodierer / -Dekodierer zu beachten?

URL kodieren behält die Struktur (/, :, &, =). Komponente kodieren maskiert alles – nimm das für einzelne Abfragewerte.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. URL-Kodierer / -Dekodierer ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
