Datenspeicher-Umrechner

Bits, Bytes, KB, MB, GB, TB mit Basen 1000 und 1024. Werte eingeben und die Schaltfläche drücken, um das Ergebnis zu sehen.

Alle Einheiten

Festplatten werden in dezimalen GB verkauft, Windows zeigt binäre GiB an. Deshalb erscheint eine „1 TB“-Platte als etwa 931 GB.

Über Datenspeicher-Umrechner

Bits, Bytes, KB, MB, GB, TB mit Basen 1000 und 1024. Umwandeln drücken – das Ergebnis erscheint im Ergebnisfeld. Alles läuft lokal im Browser, nichts wird hochgeladen. Angezeigt wird nur das aktuelle Ergebnis — ohne Verlauf und ohne Vergleich nebeneinander.

Datenspeicher-Umrechner liest „Wert“, „Von“ und „Basis“ aus dem Formular und schreibt die Antwort ins Ergebnisfeld — Festplatten werden in dezimalen GB verkauft, Windows zeigt binäre GiB an. Deshalb erscheint eine „1 TB“-Platte als etwa 931 GB. Es gibt kein Konto und keinen Serveraufruf: das JavaScript der Seite rechnet auf Ihrem Gerät.

So verwenden Sie dieses Werkzeug

  1. Öffnen Sie Datenspeicher-Umrechner über die Kategorie Umrechner oder suchen Sie es über das Suchfeld im Kopf.
  2. Füllen Sie die angezeigten Felder aus: „Wert“, „Von“ und „Basis“.
  3. Drücken Sie Umwandeln. Das neue Ergebnis ersetzt das vorherige; angezeigt wird immer nur der aktuelle Lauf, nie zwei Ergebnisse nebeneinander.
  4. Mit Kopieren kopieren Sie das Ergebnis in die Zwischenablage. Eine Meldung erscheint nur, wenn wirklich etwas kopiert wurde.

Ein Rechenbeispiel

Beim Öffnen sind diese Werte voreingestellt: Wert = 1. Drücken Sie Umwandeln einmal, um die Ausgabe zu sehen, ersetzen Sie die Werte durch Ihre eigenen und drücken Sie erneut – das neue Ergebnis ersetzt das alte.

Häufig gestellte Fragen

Werden meine Eingaben hochgeladen?

Nein. Datenspeicher-Umrechner verarbeitet „Wert“, „Von“ und „Basis“ mit JavaScript im Browser. Eingaben und Ergebnis bleiben auf Ihrem Gerät, Utilixo speichert keine Kopie.

Kann ich mehrere Ergebnisse vergleichen?

Nicht nebeneinander. Jeder Klick auf Umwandeln berechnet aus den aktuellen Eingaben neu und überschreibt das vorherige Ergebnis. Notieren Sie sich frühere Werte selbst.

Was ist bei Datenspeicher-Umrechner zu beachten?

Festplatten werden in dezimalen GB verkauft, Windows zeigt binäre GiB an. Deshalb erscheint eine „1 TB“-Platte als etwa 931 GB.

Wie nehme ich das Ergebnis mit?

Nach einem Ergebnis Kopieren drücken. Bei leerem Ergebnis erscheint keine Erfolgsmeldung.

Brauche ich ein Konto oder muss ich zahlen?

Nein. Datenspeicher-Umrechner ist kostenlos, ohne Registrierung und ohne Limit. Seite öffnen und loslegen.
